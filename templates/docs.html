INTERNAL MEMO / AUTH-07

Authentication
architecture.

A quick reference for engineers working on the research gateway.

01 / ACCESS TOKENS

Session identity

The gateway issues JSON Web Tokens (JWTs) after successful authentication. The token carries identity and authorization claims.

Engineers can inspect a token's header and payload to understand its structure. Remember that encoded claims are not necessarily confidential.

02 / API ROUTES

Available endpoints

POST /api/loginIssue a session token
GET /api/profileRead session identity
GET /api/archiveRestricted archive

03 / ARCHIVE POLICY

Authorization levels

Standard research sessions have the researcher role. Access to the restricted archive requires the admin role.

Investigation note: determine whether the server can trust the authorization claims presented by a client.

04 / FIELD NOTES

Challenge credentials

Use the provided researcher account to obtain a legitimate session token.
